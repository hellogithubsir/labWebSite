# 单 URL 使用七个画面状态序列

七张 Figma 设计图属于同一个 URL，因此官网采用一个页面入口加七个客户端画面状态的结构，而不是为每张图创建独立路由。这样保留设计要求的整页切换体验，也避免引入不必要的路由、服务端数据和跨页面状态同步。

## Consequences

- `src/app/page.tsx` 只负责进入官网壳层。
- 导航通过 `ScreenId` 和本地只读序列切换当前画面。
- 浏览器刷新默认回到初始画面；除非 Figma 明确要求，否则不把画面状态写入 query 或 hash。
- 七个画面仍然各自拥有独立的视觉实现，避免一个巨型条件组件。
